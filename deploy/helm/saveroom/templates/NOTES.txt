Hardening
---------
  All app pods run non-root with a read-only root filesystem, dropped capabilities and
  unprivileged ports (8000/3000). runAsUser/fsGroup are intentionally NOT set, so on
  OpenShift the restricted-v2 SCC assigns them from the namespace range and no SCC
  change is required.
{{- if not .Values.objectStorage.enabled }}
  NOTE: outside OpenShift nothing assigns an fsGroup, so the media PVC may mount
  unwritable. Set podSecurityContext.fsGroup if the backend cannot write to /baserow/media.
{{- end }}

  favicon: {{ if .Values.branding.faviconBase64 }}overridden at runtime via ConfigMap.{{ else }}default (set branding.faviconBase64 to override).{{ end }}
